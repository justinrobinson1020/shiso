# Shiso Plan 2: Debt — Implementation Plan

**Goal:** Ship the Debt page from the Phase 2 spec: live per-debt figures, a per-period payoff plan with funding, projections under four strategies, a promo sub-ledger, and the debt trend, plus the card-to-card envelope rule.

**Spec:** `docs/superpowers/specs/2026-09-11-shiso-phase2-debt-design.md`. Conventions are Plan 1C's (read models in `read/`, POST JSON routes through `handle`, services own writes, tests per route, `npm run check` clean at every commit, conventional commit subjects).

## Tasks, in order

1. **Schema and migration.** Add `planned_extras` and `promo_balances` to `schema.ts`; `npm run db:generate` → `drizzle/0003_*.sql`; `schema.test.ts` asserts both tables exist. Commit.
2. **Interest (pure).** `debt/interest.ts`: `promoTotal`, `accruing`, `interestEstimates`. Tests from spec §8. Commit with task 3.
3. **Projection (pure).** `debt/projection.ts`: `Debt` input type, `project(debts, strategy, opts)` returning per-debt payoff months, total interest, series; strategies plan/minimums/avalanche/snowball with rollover; promo fold and payment order per §P2 4.3; 600-month cap. Tests from spec §8. Commit.
4. **Envelope rule.** `envelope.ts`: card-to-card transfer pairs move activity between the two payment envelopes. Unit test plus a `balance_transfer` event in the property generator. Commit.
5. **Trend (db-backed, pure over rows).** `debt/trend.ts`: `debtTrend(db, { throughIso })` → rows per period with carry-forward, paid, interest, income, share. Tests. Commit.
6. **Plan service.** `debt/plan.ts`: `setPlannedExtra`, `fundShortfall` (uses `budgetForPeriod` and `assign`), `createPromo`, `updatePromo`, `closePromo`, with invariants. Tests. Commit.
7. **Read model.** `read/debt.ts`: `debtView(db, { periodId, todayIso, cadence })` assembling the five blocks. Test on the fixture extended with a loan. Commit.
8. **Routes.** `api/debt/extras`, `api/debt/fund`, `api/debt/promos`, `api/debt/promos/[id]`, `api/debt/promos/[id]/close`. Happy path + invariant test each. Commit.
9. **Page.** `routes/debt/+page.server.ts`, `+page.svelte`, `PromoEditor.svelte`, `ui/LineChart.svelte`, nav link, CSS. `npm run check`, browser check at desktop and phone widths against the production copy. Commit.
10. **Docs.** README page list, spec status → implemented. Commit.
